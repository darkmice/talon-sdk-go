The SDK decoder now makes one recursive strict JSON decode call for the complete
result, then parses already-validated tagged cells without rescanning them.
Standalone cell decoding remains strict. Missing/unknown metadata, duplicate
keys including nested Jsonb, numeric overflow, row width, and every cell kind
have regression tests. The end-to-end allocation reduction (about 8,089 per
call) agrees with the isolated decoder reduction (8,087 per call); this is
strong attribution for the allocation change, not a full latency profile.

Go's -memprofile flag caused `signal: killed` even for a goframe test process
that ran zero benchmarks. No pprof attribution is claimed. p99 at 20 samples
is especially unstable. This is local single-caller evidence, not a release
artifact or concurrent-throughput result.
